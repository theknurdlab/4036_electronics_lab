Decoding Rules & Error Formula IEC 60062 / EIA Standard
  • 4-Band Resistor Decoding: First two bands give significant digits (D1D2), third band gives decimal multiplier (10M), and fourth band gives tolerance:
    Rnominal = (10D1 + D2) × 10M Ω ± Tol%
  • 3-Digit Ceramic Capacitor Code: First two digits form the base value in picofarads (pF) and the third digit specifies the number of trailing zeros:
    C = D1D2 × 10D3 pF  (e.g., 104 → 10 × 104 pF = 100 nF = 0.1 μF)
  • Axial Inductor Color Code: Follows the same 4-band color sequence as resistors with the base unit expressed in microhenries (μH):
    Lnominal = (10D1 + D2) × 10M μH ± Tol%
  • Percentage Measurement Error: Compares the DMM/LCR measured reading against the decoded nominal value:
    % Error = Measured Value − Nominal Value Nominal Value × 100%
